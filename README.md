# AlveoGrade research dashboard

Published project snapshot. Editing happens in the local AlveoGrade Studio; run Publish AlveoGrade to GitHub.cmd in dashboard/Launchers after changes.

The registry contains 845 counted cases: 130 model cases and 715 Unlabeled-list cases. Every Unlabeled case includes its Markdown case-list number (1-715), separate from its source ID/name. The Project Library lists source names and paths; original note and PDF contents are not included. The complete `case_list.md` is available from the library and as a standalone Markdown file. Panorama previews remain available. The 80 Test (Cropped) ZIP-member cases are included in the 715 and their train/test split is unknown. Model cases and those ZIP members have crop status cropped; the other 635 have crop status not cropped. Tags remain empty for future use. Duplicate original labeled folders are excluded. Candidate annotations and historical predictions are not clinical approval.
